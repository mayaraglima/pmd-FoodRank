
# FoodRank

> Site de avaliação e recomendações de restaurantes.

---

## Sobre o Projeto

<!--
Explique qual problema o projeto pretende resolver, por que ele é importante
e qual solução foi proposta pela equipe.
-->

O projeto foi criado a partir de uma necessidade onde exista um site que nos permitisse avaliar e recomendar rstaurantes de forma simples, onde atualmente os sites que nos possibilitam fazer isso não há um foco total nisto. 

---

## Objetivos

### Objetivo Geral

<!--
Descreva o principal objetivo do projeto.
-->

O objetivo principal do nosso projeto é criar um ambiente confortavel para o usuario avaliar e recomendar restaurantes entre amigos e pessoas ao seu entorno.

### Objetivos Específicos

<!--
Liste os principais objetivos específicos do projeto.
-->

- Centralizar informações
- Facilitar decisões
- Comunidade
